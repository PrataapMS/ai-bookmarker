# Security policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems.

Report privately through GitHub:
[**Report a vulnerability**](https://github.com/PrataapMS/ai-bookmarker/security/advisories/new)
(Security tab → *Report a vulnerability*).

Include what you found, how to reproduce it, and the impact you expect. You
should get a reply within a week. Please give a reasonable window for a fix
before disclosing publicly.

## Scope

- The hosted app at https://ai-bookmarker.vercel.app
- The code in this repository

Out of scope: denial of service, volumetric or automated scanning against the
hosted app, and social engineering.

## Supported versions

Only the latest release (what's running in production) receives fixes.
